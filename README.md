# water_states_model

水的三态分子模型 · 单文件网页，双击即可打开。

## 使用

直接用浏览器打开 `water_states_model.html`。

- 无需服务器、无需联网 —— three.js 已内联在文件里
- 需要浏览器支持 **WebGL**（Chrome / Edge / Firefox / Safari 现代版本均可）
- 文件约 700 KB，建议本地打开（不要用「另存为文本」）

## 四个模式

| 模式 | 内容 |
|---|---|
| **冰 vs 水** | 同分子数下冰与液态水的真实尺度并排对比，右下角附体积刻度尺 |
| **气态间距** | 水蒸气按真实比例摆放，看分子间距有多大 |
| **温度演化** | 拖动温度滑块，看冰 → 水 → 水汽的连续变化（含 0 °C / 100 °C 相变平台） |
| **冰浮水面** | 冰浮在水面上，露出约 8% 的体积 |

## 操作

- 拖拽旋转 · 滚轮缩放 · 右键拖拽平移
- 左栏可调分子个数、显示选项、剖切
- 右上角「模型说明」有数据来源与建模方式

## 数据

晶胞参数、密度、分子间距、潜热、淹没比例均为实测值。详见页面内「模型说明」。
